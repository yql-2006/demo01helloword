# UML PlantUML 图解说明

此目录包含项目建模所需的 PlantUML 源文件。可以使用任意支持 PlantUML 的工具渲染这些图表，例如：
- Visual Studio Code + PlantUML 插件
- PlantUML 在线渲染器
- IntelliJ IDEA PlantUML 集成

## 包含的图表
- `use_case.puml`：用例图
- `architecture.puml`：架构图
- `class_diagram.puml`：类图
- `activity_diagram.puml`：活动图
- `er_diagram.puml`：ER 图
- `sequence_diagram.puml`：时序图
- `gantt_chart.puml`：甘特图

## 渲染方法
1. 打开 PlantUML 编辑器并加载 `.puml` 文件。
2. 生成 PNG/SVG 或导出 PDF。
3. 如果使用 VS Code，可安装 PlantUML 插件并选择“Preview Current Diagram”。

## 环境说明
本环境仅创建了 PlantUML 源文件，无法直接下载桌面客户端或生成桌面快捷方式。因此请在本地机器上安装所需建模工具并打开这些源文件。
